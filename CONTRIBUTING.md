# Contributing

electron-vite-plus is an experimental project. Reproductions and focused pull requests are welcome.

## Development

```bash
npm install
npm run check
npm test
npm run build:all
```

Use a minimal fixture under `tests/fixtures` for behavior changes. Changes to development reload behavior should include an integration test.

## Pull requests

Keep changes focused, explain the user-facing impact, and include the commands used for validation. Do not commit generated `out` directories.
